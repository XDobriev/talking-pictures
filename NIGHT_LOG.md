## Что готово

- **Три сцены, 26 уровней** — всё, что запланировано для MVP (бонус «Ночной лес» — после релиза):
  - **Лес** — 10 уровней (кто это, на слух, глаголы, место, цвет, насекомые, предлоги, эмоции).
  - **Ферма** — 8 уровней: кто это ×2, на слух (мяу, кукареку, бе-е, га-га-га), «кто кушает», овощи, красное, «на заборе», «кому грустно».
  - **Двор** — 8 уровней с упором на **глаголы** (качается, катается, прыгает, едет, играет, лепит; эхо-повтор тоже глаголы), игрушки, «что в небе», красное, звуки двора, «кому грустно».
- **Механики**: панель заданий, полёт находки в слот, эхо-пауза «Скажи: …», подсказки по бездействию (12 с / 25 с), светлячок-подсказка, обучающая лапка, пузыри при беспорядочном тапанье, окно победы с наклейкой, меню-тропинка с вкладками сцен, альбом наклеек, родительская зона (удержание 3 с).
- **Арт** — Figma (файл «Говорящие картинки — арт», https://www.figma.com/design/potj4BW3cxBxeVVNUzlaqk): лес 2:2, ферма 7:2, двор 8:2, иконка 9:2, обложка 10:2. Все сцены с первой попытки. Промпты — [art-prompts/](art-prompts/). Сцены «запечённые» (`baked: true`): герои кадрируются из фона. Разметку проверять наложением хитбоксов на картинку до запуска.
- **Звуки животных**: 17 настоящих записей BigSoundBank (CC0) → `src/assets/sfx/`, источники — `src/assets/sfx/LICENSES.md`, пересборка — `npm run sfx`. Синтезом остались поросёнок, голуби, шелест, капли. **Не прослушаны человеком** (нейросеть на коротких звуках животных ненадёжна).
- **Промоматериалы** (`promo/`, `npm run promo`): иконка 512, обложка 800×470, 4 скриншота 1920×1080, тексты карточки (`promo/texts.md`, лимиты длины проверены). **Нет видео** — снимать после озвучки (нужен `ffmpeg-static`).
- **Платформа**: мок (localhost) и Яндекс Игры (проверено через `@yandex-games/sdk-dev-proxy`). Требования модерации закрыты в коде (PLAN.md §10.4). В релизе синтез речи браузера отключён.
- **Тесты**: `npm test` — 52 (общие правила разметки для каждой сцены, уровни всех сцен); `npm run e2e` — 16 проверок в Chrome, включая уровни фермы и двора.
- **Репозиторий**: https://github.com/XDobriev/talking-pictures (приватный). После коммитов — `git push`.

## Голос

- Голоса: рассказчица **Leda**, светлячок **Achernar** (Gemini TTS, модель `gemini-2.5-flash-preview-tts`). Ключ — в `.env`; его стоит пересоздать (был в чате).
- **Озвучено и проверено расшифровкой: 92 из 252 фраз.** Осталось 160 ≈ 23 запроса по 7 фраз ≈ 2–3 дня лимита (10 запросов в сутки на модель; сброс в 10:00 по Москве).
- Цикл на каждый день: `npm run voice` → `npm run voice:qa -- --no-trim --only=voice/new.txt --delete-bad` (команду печатает сам `voice.mjs`). Удалённые проверкой — переозвучатся на следующий день.
- Если проверка падает на «fetch failed» / 503 — это сбой сети или API, а не файлов: перезапустить только непроверенные.

### Что выяснилось 19.10

- **Проверка пачкой врёт** — модель путает порядок ответов; `voice-qa` проверяет по одному файлу и сама переключает текстовые модели при суточном лимите.
- **Нарезка**: `splitPhrases` (`scripts/lib/audio.mjs`) выбирает разрезы с учётом ожидаемой длительности фраз (298–299/300 верных синтетических пачек против 231 у старой).
- **Пачки по 7**, не 14 (на 14 модель обрывается). **`gemini-3.8-flash-tts` не использовать** — зачитывает инструкцию.
- **Защита пачек** в `voice.mjs`: кусок вне 0,05–0,3 с на единицу веса или медиана пачки вне 0,07–0,22 → пачка отбрасывается. Пороги подобраны по 21 сохранённой пачке: проходят ровно 7 хороших (включая одну неторопливую, проверенную расшифровкой), отбрасываются все 14 плохих. Сырой звук — `voice/raw/batch-*`, перерезать — `node scripts/voice.mjs --recut --only=…`.
- Пачки «curious» (эхо по слогам) — самые капризные: модель тянет паузы между словами. Если брака будет много — уменьшить для них пачку до 4–5.

## Озвучка по расписанию (с 20.10)

- Задача Windows `TalkingPictures-DailyVoice`, каждый день в 11:30: `scripts/daily-voice.mjs` → озвучка до лимита → проверка расшифровкой всего непроверенного → брак удаляется. Сводка — `voice/logs/last.txt`, подробно — `voice/logs/<дата>.log`. Выключить: `powershell -ExecutionPolicy Bypass -File scripts/schedule-voice.ps1 -Remove`.
- Реестр проверенных — `voice/verified.txt`; релиз не соберётся с непроверенными файлами. Результаты ночных запусков **не коммитятся сами** — закоммитить в следующей сессии.
- Запасные TTS-модели (`gemini-3.8-flash-lite-tts`, `gemini-3.8-flash-tts`) работают в режиме `--plain` (только фразы; `systemInstruction` они не принимают). Подключаются строкой в `voice/extra-models.txt` — **только после прослушивания** `voice-compare/` пользователем.

## Производительность (19.10)

- **dist не очищался**: висел забытый `sdk-dev-proxy` от 18.10, а `fs.rmSync` в Node 24 на Windows молча не работает при кириллице в пути. Сборка была 8,3 МБ (11 старых копий скрипта) → теперь 3,4 МБ. Очистка — `scripts/clean.mjs` (unlink/rmdir), не `rmSync`.
- Эмуляция бюджетного Android (CPU ×4, Fast 3G): первый экран ~5 с. Предзагрузка фона и шрифтов (плагин в `vite.config.ts`) сократила задержку обнаружения картинки 2,6 → 0,7 с; ленивые экраны и удаление векторных заглушек — стартовый JS 164 → ~148 КБ gzip. Дальше упирается в React + framer-motion (66 + 44 КБ gzip) — замена не стоит риска; на Яндексе это время закрывает их загрузчик.
- Плавность в игре: самая длинная заминка при находке — 134 мс при ×4 (норма отклика < 200 мс). Состав сборки — `npm run analyze`.

## Решения, принятые без пользователя (проверить)

- Первый запуск ведёт сразу в уровень 1, без меню.
- Все уровни открыты сразу, следующий подсвечен.
- Реклама — только interstitial по «Дальше» / «Ещё раз»; rewarded пока не используется.
- Во дворе эхо-повтор — на глаголы («Скажи: ка-ча-ет-ся!»), а не на названия.
- Тексты карточки (`promo/texts.md`) написаны без согласования.
- `@yandex-games/sdk-dev-proxy` тянет старый express с уязвимостями — только локальный dev-инструмент, в сборку не попадает.
