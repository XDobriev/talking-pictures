В меню — вкладки «Лес» / «Ферма» («Двор» — скоро). Новые звуки животных синтезируются (`sfx.ts`: moo, bark, meow, baa, cluck, neigh, crow) — грубые наброски. Фермы требуют 74 новые фразы; голоса для них ещё нет.
- **Звуки животных** (19.10): 15 настоящих записей из BigSoundBank (CC0) → `src/assets/sfx/*.mp3` (150 КБ), источники — `src/assets/sfx/LICENSES.md`, пересборка — `node scripts/sfx.mjs` (качает через Playwright: сайт отдаёт 403 простым запросам). Поросёнок и шелест/капли пока синтезируются. **Не прослушано**: проверка нейросетью на коротких звуках животных ненадёжна (противоречит сама себе) — нужен человек. Подозрения у модели: курица, сова, мышь, лягушка; поменять запись — номер в `SOURCES` в `scripts/sfx.mjs` и `--force`.
- **Платформа**: мок (localhost) и Яндекс Игры. Проверено через `@yandex-games/sdk-dev-proxy`: init, getPlayer/getData, LoadingAPI.ready, GameplayAPI start/stop на уходе со вкладки.
- **Требования модерации** закрыты в коде (см. PLAN.md §10.4).
- **Тесты**: `npm test` (36 юнит-тестов; общие правила разметки проверяются для каждой сцены), `npm run e2e` (15 сквозных проверок в Chrome, включая ферму; скриншоты в `screenshots/`).
- **Упаковка**: `npm run release` → `release/talking-pictures-0.1.0.zip` (сейчас останавливается: не озвучены 64 фразы — так и задумано).

## Голос — в процессе

- Выбраны голоса: рассказчица **Leda**, маскот-светлячок **Achernar** (Gemini TTS). Ключ — в `.env` (не в git). Ключ был вставлен в чат — позже лучше пересоздать в AI Studio.
- Бесплатный лимит: **10 запросов в сутки на модель**, у каждой модели свой. Поэтому пакетный режим: много фраз за один запрос, резка по паузам.
- **Озвучено и проверено расшифровкой: 43 из 107** (42 от модели 2.5 + `bunny_ask`). Остальные 64 удалены или ещё не делались.

### Что выяснилось 19.10 (вторая сессия)

- **Проверка пачкой врёт**: если отдать модели 12 аудио за раз, она путает порядок ответов. Теперь `voice-qa` по умолчанию проверяет **по одному файлу** и сама переключается между текстовыми моделями при суточном лимите (`gemini-2.5-flash` для новых ключей закрыта).
- **Старая нарезка портила фразы**: брала N−1 самых длинных пауз, и «Скажи: у-точ-ка» рвалась по внутренней паузе — дальше вся пачка съезжала на одну фразу (20 из 62 файлов говорили чужой текст). Новая `splitPhrases` (`scripts/lib/audio.mjs`) выбирает разрезы с учётом ожидаемой длительности каждой фразы: на синтетике 298–299/300 верных пачек против 231.
- **Пачка из 14 фраз слишком длинная**: модель 2.5 прочитала пару фраз и остановилась. Брать `--batch=7`.
- **`gemini-3.8-flash-tts` не годится**: зачитывает вслух саму инструкцию («Прочитай по-русски тепло…»). Все 60 её файлов удалены. Теперь `voice.mjs` отбрасывает пачку, если длительность неправдоподобна (норма 0,08–0,18 с на единицу веса фразы) — на сохранённых плохих пачках ловит 11 из 11.
- Сырой звук каждой пачки сохраняется в `voice/raw/batch-*.pcm` — `node scripts/voice.mjs --recut` перережет без новых запросов.
- В релизе синтез речи браузера **отключён** (п. 1.23), а `npm run release` не соберёт архив, пока озвучены не все фразы.

## Следующие шаги (по порядку)

1. Когда обновится суточный лимит (сутки по тихоокеанскому времени): `node scripts/voice.mjs --batch=7 --model=gemini-2.5-flash-preview-tts`. Не озвучено 138 из 181 фразы (64 лесных + 74 фермы) ≈ 20 запросов = 2 дня лимита; лесные идут первыми (порядок `PRIORITY` в `voice.mjs`). Не смешивать с другими TTS-моделями без прослушивания.
2. Сразу после: `npm run voice:qa -- --no-trim --only=voice/new.txt --delete-bad` (команду печатает сам `voice.mjs`). Удалённые — переозвучить на следующий день.
3. Пользователь слушает игру с голосом (`npm run dev`) и даёт обратную связь.
4. Сцена «Двор» тем же пайплайном (стиль-блок и правила композиции — PLAN.md §8; шаблон — [art-prompts/farm.md](art-prompts/farm.md): герои «слева направо», у каждого действие и место). Проверка разметки: наложить хитбоксы на картинку (так ловятся сдвиги до запуска игры).
5. Промоматериалы по PLAN.md §10.5, регистрация в Консоли и РСЯ как самозанятый (§10.6).

Открытый вопрос: попробовать вынести служебную инструкцию в `systemInstruction` запроса — возможно, тогда и новые TTS-модели перестанут её зачитывать. Проверять одним запросом и только с последующей расшифровкой.
