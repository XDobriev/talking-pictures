# «Говорящие картинки: найди и назови»

План проекта. Детская развивающая веб-игра для малышей 3–6 лет. Механика: поиск предметов на большой живой картинке с голосовой озвучкой. Цель: развитие речи.

> Статус: идея / планирование. Код ещё не начат.
> Рабочее название: **Говорящие картинки**. Подзаголовок: *найди и назови · развитие речи · 3–6 лет*.

---

## 1. Суть продукта

**Одной фразой:** книжка-разглядывалка, которая разговаривает с ребёнком. Она просит найти героя, называет его, рассказывает, что он делает, и предлагает повторить.

| | Ребёнок (играет) | Родитель (выбирает) |
|---|---|---|
| Что получает | Красивый живой мир, «чпок!», всё оживает от касания, всегда успех | Польза для речи: словарь, глаголы, предлоги, эмоции |
| Чего боится / что раздражает | Сложность, текст, проигрыш | Шок-реклама, случайные покупки, «залипание», перевозбуждение |
| Наш ответ | Ноль негатива, голос вместо текста | Спокойный темп, родительский контроль, понятная методика |

**Жанр-основа.** Виммельбух (нем. *wimmeln*, «кишеть»): большая детальная картинка, на которой много героев и мини-историй. Примеры: Ротраут Сузанне Бернер, Али Митгуч, «Где Уолли?». В названии игры этого слова нет, родители его не знают.

---

## 2. Почему эта ниша (стратегия голубого океана)

**Красный океан детских игр на Яндекс Играх:** сборники мини-игр «всё в одном» (раскраски, пазлы, сортировки), много рекламы, мельтешение, лицензионные герои у крупных игроков. Верх тегов «Детские» занимают Obby, Sprunki, «брейнроты», то есть аудитория 7–12 лет.

**Пустое место:** качественный поиск предметов для малышей. На Яндексе поиск предметов почти весь для взрослых. Развитие речи (ЗРР — частая тревога родителей) обычно подаётся как «занятия с логопедом», а не как игра. Эмоции для обычных дошкольников почти не покрыты: приложения про эмоции делаются в основном для детей с РАС.

### Сетка «Убрать / Снизить / Усилить / Создать»

| Убрать | Снизить |
|---|---|
| Таймеры, проигрыши, штрафы | Число механик: одна глубокая вместо двадцати поверхностных |
| Текст на экране | Частоту рекламы |
| Покупки, доступные ребёнку | Яркость, мельтешение, перевозбуждение |
| Лицензионных героев | |

| Усилить | Создать |
|---|---|
| Арт уровня хорошей книжки | **Говорящую картинку**: всё называется голосом |
| Качество голоса и интонаций | **Эхо-паузу**: «Скажи: бе-лоч-ка!» и пауза, чтобы ребёнок повторил вслух |
| Методику (понятная польза для речи) | **Возрастные задания на одной сцене** |
| | **Засыпалку**: вечерняя сцена, игра сама мягко заканчивается |

## 3. Методика: чем игра развивает речь

Задания идут по естественному порядку развития речи: **предмет → действие → признак → место → чувство → история**.

| Ступень | Возраст | Навык | Пример задания (голосом) |
|---|---|---|---|
| 1. Кто это? | 3+ | Существительные, пассивный словарь | «Найди белочку!» |
| 2. Кто так говорит? | 3+ | Звукоподражание, слуховое внимание | «Кто говорит „кря-кря“?» |
| 3. Кто что делает? | 3–4 | Глаголы | «Найди, кто спит» |
| 4. Какой? | 4+ | Прилагательные: цвет, размер | «Найди что-то красное» / «Найди самый большой гриб» |
| 5. Где? | 4–5 | Предлоги: на, под, за, в | «Кто сидит под деревом?» |
| 6. Что чувствует? | 5+ | Эмоции, эмпатия | «Кому грустно? Помоги ему!» |
| 7. История | 5–6 | Связная речь, последовательность | «Проследи за ёжиком: куда он идёт?» (позже) |

**Эхо-приём.** После находки голос называет предмет («Это белочка. Она грызёт орешек»), затем говорит «Скажи: бе-лоч-ка!» и выдерживает паузу ~2 секунды. Микрофон **не используем**: это риски модерации и персональных данных детей. Повторение вслух — приглашение, а не проверка.

**Подсказки для родителя.** В родительском меню на каждую сцену 3–4 вопроса для совместной игры: «Расскажи, что делает лиса?», «Почему зайчик грустит?». Это переносит в цифру главную силу бумажной разглядывалки — разговор со взрослым.

> Методику до релиза желательно показать практикующему логопеду (знакомым, на форуме) хотя бы для «санити-чека» формулировок.

## 4. Игровой цикл

```
Сцена → голос даёт задание → ребёнок ищет (сцена живая, всё откликается)
      → находка: предмет «оживает» + звук + голос называет + эхо-пауза
      → предмет летит в слот панели заданий
      → все цели найдены → праздник (конфетти, 3 звезды) → наклейка в альбом
```

- **Одна сцена = 5–6 уровней** с разными типами заданий (ступени 1–6). Это экономит арт и закрывает требование Яндекса о «более 10 минутах контента» (п. 2.9) и о росте сложности (п. 2.8).
- **Рост сложности:** число целей 3 → 5 → 7; цели мельче и лучше спрятаны; задания от «кто?» к «где?» и «что чувствует?».
- **Живой мир:** касание по декорациям вызывает реакцию (куст шуршит и выпускает бабочек, облако капает дождём, кот мурлычет).
- **Неверное касание** — это не ошибка, а маленькое открытие: предмет просто озвучивается («Это ёлочка»). Тоже работает на словарь.

## 5. Контент MVP

| Сцена | Почему | Уровни |
|---|---|---|
| **Лес** | Классика, дикие животные, много признаков (грибы, ягоды, цвета) | 6 |
| **Деревня / ферма** | Домашние животные — первые слова и звукоподражания | 6 |
| **Двор / площадка** | Город, люди, действия, эмоции детей | 6 |
| *Бонус: Ночной лес (засыпалка)* | Спокойный финал, «уложи зверят спать» | 3 |

На каждой сцене **20–30 интерактивных объектов** (цели + декорации). Итого MVP: 3 сцены, 18 уровней и бонус.

**Мета-игра:** «Альбом наклеек». За уровень ребёнок получает анимированную наклейку героя и может приклеить её на свою полянку. Это удержание D1/D7.

**Маскот (предложение):** светлячок-проводник. Он же голос рассказчика и он же подсказка («Светлячок» показывает, где цель). Один персонаж закрывает три функции. Окончательно решаем после теста арта.

## 6. Детский UX (обязательные правила)

- **Ноль негатива:** нет Game Over, таймеров, штрафов. Финал всегда 3 из 3 звёзд.
- **Мультитач:** обрабатываем только первичное касание (`e.isPrimary`), ладони на краях экрана игнорируются.
- **Хитбоксы** на 25–30% больше спрайта, минимум 52×52 CSS px. Видимый предмет не меньше ~6,5% ширины и ~8% высоты экрана.
- **Беспорядочное тапанье** (>4 касаний в пустоту за 2 с) запускает мыльные пузыри с приятным звуком.
- **Подсказки:** через 12 с бездействия покачивается силуэт в панели; через 25 с цель мягко пульсирует; кнопка «Светлячок» показывает цель.
- **Обучение без слов:** на первом уровне полупрозрачная лапка показывает механику.
- **Родительский контроль:** «удерживайте кнопку 3 секунды» или «введите цифры: семь, два, девять» (словами). Пример «2 + 3» шестилетка решит сам.
- **Экран:** холст 16:9 (1920×1080) с леттербоксингом, фон может тянуться до 21:9, интерактив только внутри 16:9. Только альбомная ориентация, заглушка «поверните экран». Отступ панели ≥24 px от нижнего края.
- **Спокойствие:** приглушённая палитра, мягкие звуки, музыка ~0.25, звуки ~0.85–1.0, раздельные тумблеры в родительском меню.

## 8. Пайплайн арта

Инструменты: **Gemini** (подписка, черновики и сцены) → **Figma** (монтажный стол: вырезка, слои, разметка). Figma MCP `generate_image` работает на тех же моделях (Gemini / GPT-image), но тратит AI-кредиты Figma, поэтому генерируем в Gemini, а собираем в Figma. Claude делает векторный UI (кнопки, панель, иконки, светлячок) и промпты.

1. **Стайлгайд (style bible):** 1 страница с палитрой, обводкой, светом, 3 референсами. Каждый промпт начинается с одного и того же стиль-блока.
2. **Генерация цельной сцены** 16:9 (2K), сразу со всеми героями. Стиль у всех элементов совпадает.
3. **Вырезка целей в Figma:** каждый герой становится отдельным слоем с прозрачным фоном (удаление фона), а дыру в фоне дорисовываем (инпейнтинг в Gemini).
4. **Силуэты для панели заданий генерируем кодом** из спрайта (CSS `filter: brightness(0)` + прозрачность). Отдельный арт не нужен.
5. **Экспорт:** WebP, фон ≤350 КБ, спрайты маленькие. Имена файлов только латиницей (п. 1.22).
6. **Разметка координат:** dev-инспектор в игре (Shift+D), клик даёт координаты в процентах.

**Тест арта (этап 0):** одна сцена «Лес», 5 вырезанных героев. Если укладываемся в 2–3 вечера, пайплайн рабочий.

## 9. Пайплайн озвучки (только нейросеть)

**Кастинг голоса:** Gemini TTS против Yandex SpeechKit на 10–15 эталонных фразах. Критерии: тепло, медленный темп, улыбка в голосе, **правильные ударения**.

| Движок | Плюсы | Минусы |
|---|---|---|
| Gemini TTS | Живая подача, интонация задаётся словами («тепло и медленно, как воспитательница») | Ударения проверять вручную; насколько хорошо он справляется с русским и какие у него коммерческие условия, проверить |
| Yandex SpeechKit | Нативный русский, ручные ударения (`+` перед ударной гласной), ~1 320 ₽ за 1 млн символов, российский сервис | Чуть более «дикторская» подача |
| ElevenLabs | — | Заблокирован для России, отпадает |

**Правило:** один голос рассказчика на всю игру. Второй голос допустим только для маскота как отдельного персонажа.

**Процесс:**
1. Все фразы лежат в одной таблице `voice/phrases.csv`: `id, text, text_with_stress, emotion`.
2. Скрипт генерирует аудио через API, нормализует громкость (LUFS), режет тишину, сохраняет `ogg` + `mp3`.
3. Добавили уровень — перегенерировали за минуту.

**Объём:** ~25 объектов × (имя + факт + эхо) ≈ 80–100 фраз на сцену, плюс ~40 общих (похвала, задания, меню). На MVP ~350 фраз.

**Звуки животных и мира:** freesound (CC0), Pixabay, только с коммерческой лицензией. Источник и лицензию каждого звука записываем в `assets/sounds/LICENSES.md`.

## 10. Архитектура

**Стек:** TypeScript, React 18+, Vite (`base: './'`), Tailwind CSS, Framer Motion, Howler.js, canvas-confetti. Мобильные сборки позже через **Capacitor**.

### 10.1. Слой-адаптер платформы (с первого дня)
Игра не знает, где запущена. Все внешние вызовы идут через один интерфейс:

```ts
interface Platform {
  init(): Promise<void>;
  gameReady(): void;                      // LoadingAPI.ready()
  gameplayStart(): void; gameplayStop(): void;
  showInterstitial(): Promise<void>;
  showRewarded(): Promise<boolean>;       // true = награда выдана
  save(data: SaveData): Promise<void>;
  load(): Promise<SaveData | null>;
  onPause(cb: () => void): void; onResume(cb: () => void): void;
}
// Реализации: YandexGamesPlatform, MockPlatform (localhost), позже RuStorePlatform
```

### 10.2. Состояние: сцена и оверлей раздельно
```ts
type Scene = 'LOADING' | 'MENU' | 'LEVEL' | 'ALBUM';
type LevelPhase = 'INTRO' | 'PLAYING' | 'FOUND_FLYING' | 'COMPLETED';
type Overlay = null | 'AD' | 'PARENTAL_GATE' | 'PARENT_MENU' | 'HINT';
```
Реклама и родительский контроль накладываются поверх игры и не стирают, где был игрок.

### 10.3. Данные: объекты с признаками, задания-запросы
Объект на сцене описывается признаками. Задание — это фильтр по признакам. Новые уровни собираются без нового арта.

```json
{
  "id": "squirrel",
  "sprite": "scenes/forest/squirrel.webp",
  "rect": { "x": 72.5, "y": 34.0, "w": 8.0, "h": 10.0 },
  "voice": { "name": "forest_squirrel_name", "fact": "forest_squirrel_fact", "echo": "forest_squirrel_echo" },
  "sound": "squirrel_chatter",
  "tags": { "kind": "animal", "color": "orange", "size": "small", "action": "eat", "place": "on_tree", "emotion": "happy" }
}
```
```json
{ "level": "forest_3", "taskVoice": "task_find_who_sleeps", "query": { "action": "sleep" }, "count": 3 }
```

### 10.4. Чек-лист требований Яндекс Игр
- [ ] SDK только по документации; `LoadingAPI.ready()` в момент готовности; страховочный вызов через 15 с
- [ ] `GameplayAPI.start/stop` на поиске / паузе / победе / меню
- [ ] Звук гаснет при потере фокуса и во время рекламы; `game_api_pause` / `resume`; `Howler.ctx.resume()` для iOS
- [ ] Реклама только в логических паузах, rewarded только по кнопке, с явным указанием награды
- [ ] Никаких `alert` / `confirm`, внешних ссылок, сторонних CDN (кроме SDK)
- [ ] `index.html` в корне архива, файлы только латиницей, архив ≤100 МБ, первый экран ≤6 МБ
- [ ] Прогресс в облаке (`player.setData`), если есть покупки
- [ ] Контент >10 минут, сложность растёт

## 11. Метрики и критерии успеха

Телеметрия без персональных данных: `level_start`, `target_found` (+ время), `wrong_tap`, `hint_used`, `level_complete`, `session_end`.

**Гипотезы для проверки на Яндекс Играх (первые 4–6 недель):**
- Среднее время сессии ≥ 6–8 минут.
- Доля прошедших первую сцену целиком ≥ 40%.
- Возвраты D1 заметно выше среднего по нашим другим метрикам, отзывы родителей упоминают речь или пользу.

**Если гипотезы подтверждаются** — сборка под RuStore (Capacitor) с подпиской и новые сцены. **Если нет** — смотрим, где застревают, и пробуем другую тему на том же движке.

## 13. Риски

| Риск | Что делаем |
|---|---|
| Малышовый трафик на Яндекс Играх меньше ожидаемого | Считаем Яндекс полигоном; основная ставка — мобильные магазины |
| Арт выглядит «вклеенным» или разнородным | Цельная сцена → вырезка → инпейнтинг; один стиль-блок промптов |
| Ошибки ударений в озвучке | Ручная разметка ударений, прослушивание каждой фразы |
| Модерация (10 минут контента, звук, SDK) | Чек-лист из п. 10.4 до отправки |
| Доход обнулят из-за ботов | Не зависим от одной площадки; не кликаем по своей рекламе |
| Методика окажется «для галочки» | Санити-чек у логопеда, наблюдение за реальными детьми |
